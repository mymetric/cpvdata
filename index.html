Logica de sessionizacao

Cada mensagem e ordenada por contact_id + message_at. Usando LAG, calcula-se o gap em horas entre mensagens consecutivas do mesmo contato. Se o gap for > 24 horas, uma nova conversa e criada via running SUM.

mensagens ordenadas por contact_id + message_at
  -> LAG para calcular gap entre mensagens
  -> gap > 24h = nova conversa (running SUM)
  -> GROUP BY contact_id + conversation_no
